ملف تماضر — تعليمات التشغيل والتحديث

1. فكّي الضغط، ثم افتحي index.html في المتصفح.
2. انقري على أي ملف مشروع: يعمل الصوت مرة واحدة عند الفتح. يمكنك كتمه من الزر أعلى الصفحة.
3. لكل مشروع: نبذة، هدف، المشكلة التي يعالجها، وحتى خمس مهارات مستخدمة.
4. اختيار صورة من جهازك يعرض معاينة مؤقتة فقط؛ لا يرفعها إلى الموقع ولا يحفظها بعد مغادرة ملف المشروع.
5. لإظهار صورك لكل الزوار، ضعي الصور داخل assets بالأسماء التالية (صيغة WebP):
dependency-guard.webp
secure-payment.webp
tifl.webp
fixflow.webp
athar.webp
capsule.webp
muqabil.webp
hail-memory.webp
marsad.webp
order-payment-reconciliation.webp

المرفق يتضمن أربع صور توضيحية من ملفك الأصلي. المشاريع الستة الأخرى تعرض مساحة للصورة حتى تضيفي صورك. يفضّل استخدام لقطات فعلية من واجهات مشاريعك، بنسبة 4:3 أو 16:9؛ يعرض الإطار الصورة كاملة دون قص.

6. لتغيير الصوت، استبدلي الملف داخل assets بنفس الاسم:
resident-evil-4-herb-pick-up-sound-effect.mp3
7. لتحديث GitHub Pages: افتحي مستودع tamadur-portfolio، ثم Add file > Upload files، وارفعي index.html ومجلد assets بمحتوياته، ثم Commit changes. ارفعي محتويات المجلد مباشرة؛ لا ترفعي ملف ZIP وحده.
8. التعديلات في هذه الحزمة؛ الموقع المنشور لم يُعدّل تلقائيًا.
9. فتح رابط مشروع مباشرةً أو إعادة تحميله لا يشغّل الصوت قبل تفاعل المستخدم، وفق قيود تشغيل الصوت في المتصفح. الصوت يعمل عند النقر على ملف أو تبويب مشروع، وكذلك ملف «عنّي».

تحديث اختيار اللغة والتواصل:
- اختاري العربية أو English من أعلى الصفحة؛ يتغير المحتوى بالكامل ويُحفظ الاختيار على المتصفح.
- البريد الإلكتروني أسفل اليمين وLinkedIn أسفل اليسار في اللغتين.
- رقم الجوال غير مضاف لأنه لم يُرسل. يمكن إضافته في index.html داخل CONTACT_PHONE، وسيظهر رابط الاتصال في التذييل.
- هذا التحديث لم يُرفع إلى GitHub؛ الاتصال رفض الكتابة بصلاحياته الحالية.

تحديث صفحة عنّي:
تصميم داكن بلمسات ذهبية، وبطاقات للمهارات وخبرة التدريب، وروابط تواصل مرتبة.
روابط التشغيل غير المؤكدة: ذاكرة حائل، مرصد، مطابقة الطلبات والدفعات. أبقينا روابط المستودعات المتوفرة ولم نضف روابط تشغيل غير موثقة.
